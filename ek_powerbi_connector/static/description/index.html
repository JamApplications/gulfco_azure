Odoo PowerBI Direct Connector

from

EKIKA

The Odoo PowerBI Direct Connector Module enables seamless integration between Odoo and PowerBI Desktop. This module allows users to directly fetch specific tables and fields from Odoo into PowerBI. It supports user-based access (with company restrictions) for data security, and sudo mode, providing full access for administrators.

Power BI embedded analytics allows you to embed your Power BI reports in Odoo. You can Deliver compelling data experiences for your end users, enabling them to take action based on insights from your solutions data.

You need to grant administrative access for admin tasks such as create, read, update, and delete records.

PATH: Users & Companies -> User -> Access Rights -> OTHER -> PowerBI

Registering the Application on Microsoft Azure:

In this step, users must register their application on the Microsoft Azure portal. Under the Redirect URI section, ensure the application type is set to Web. Then, enter your domain followed by the mandatory endpoint /powerbi/embed/oauth/callback. This configuration is essential for enabling OAuth-based authentication with Power BI Embedded within Odoo.

Registered Application Overview:

Here you can see that we have already registered our application successfully in the Microsoft Azure portal.

Application Overview:

Here you can see the Overview section of the registered application in Microsoft Azure. It displays important details such as the application name, Application (client) ID, Directory (tenant) ID, and other essential information.

You will need to copy the Application (client) ID, Directory (tenant) ID, and the Client Secret (generated under the Certificates & secrets section) and enter them into Odoo's System Parameters. These credentials are required to establish a secure connection between Odoo and the Power BI service for embedding dashboards.

Note that copy the clients secret from the Value field.

Odoo System Parameters Configuration:

Here in the relevant fields, you need to paste the Application (client) ID, Directory (tenant) ID, and the Client Secret that you copied from the Microsoft Azure portal.

PATH: Technical -> Parameters -> system Parameters

Power BI Report Details and Odoo Dashboard Configuration:

From the Power BI app at app.powerbi.com, you need to open your report and copy the Group ID and Report ID of the report you want to embed.

Then, in Odoo, go to the Dashboard Configuration section and click on New to create a new dashboard entry. Fill in the required details and paste the copied Group ID and Report ID. This step is necessary to link your Power BI report with your Odoo system for embedding.

Embedded Report in Odoo:

Power BI report has been successfully embedded into Odoo. You can now view the report directly within the Dashboard menu.
